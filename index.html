Por que aprender JavaScript?

JavaScript é a linguagem que roda em praticamente todo navegador do planeta. Com ela você pode criar interatividade em páginas web, construir aplicações completas (front-end e back-end, com Node.js), aplicativos mobile e até programas de desktop.

  • É a única linguagem nativa dos navegadores.
  • Tem uma comunidade enorme e infinidade de bibliotecas.
  • Serve tanto para pequenos scripts quanto para sistemas complexos.

Como usar este material

Cada módulo tem: uma explicação objetiva, um bloco de código comentado e uma atividade proposta para você praticar. Recomendamos copiar os exemplos para um arquivo .html ou para o console do navegador e experimentar variações.

01

Variáveis e tipos de dados

Variáveis armazenam valores. Em JavaScript moderno usamos let para valores que podem mudar e const para valores fixos. Evite var, que pertence a uma sintaxe mais antiga e tem comportamento menos previsível.

Tipos primitivos

  • string — texto, entre aspas.
  • number — números inteiros e decimais.
  • boolean — true ou false.
  • undefined — variável declarada sem valor.
  • null — ausência de valor, definida propositalmente.
variaveis.jsJavaScript
1const nome = "Ana";         // texto — não muda
2let idade = 28;             // número — pode mudar
3let ativo = true;            // booleano
4let cidade;                    // undefined até receber valor
5
6idade = idade + 1;
7console.log(typeof nome, typeof idade, typeof ativo);
8// "string" "number" "boolean"
Atividade proposta
  1. Crie três variáveis: nomeCompleto, anoNascimento e estudante (booleana).
  2. Calcule a idade aproximada da pessoa a partir do ano atual e imprima uma frase completa com console.log.
  3. Use typeof para imprimir o tipo de cada variável criada.
Ver dica

Use template strings para montar a frase: `Olá, ${nomeCompleto}!`

Operadores

Operadores combinam ou comparam valores. Os principais grupos são aritméticos, de comparação, lógicos e de atribuição.

operadores.jsJavaScript
1// Aritméticos
2console.log(10 + 5, 10 % 3, 2 ** 10); // 15 1 1024
3
4// Comparação (=== compara valor e tipo)
5console.log(5 === "5");   // false
6console.log(5 == "5");    // true (evite o ==)
7
8// Lógicos
9const maiorDeIdade = true;
10const temCarteira = false;
11console.log(maiorDeIdade && temCarteira); // false
12console.log(maiorDeIdade || temCarteira); // true
Atividade proposta
  1. Declare duas variáveis numéricas e imprima o resultado das quatro operações básicas entre elas.
  2. Escreva uma expressão que verifique se um número é par usando o operador %.
  3. Combine dois booleanos com && e || e explique em um comentário o resultado.

04

Loops (laços de repetição)

Loops repetem um bloco de código enquanto uma condição for verdadeira, ou para cada item de uma coleção.

loops.jsJavaScript
1// for clássico
2for (let i = 1; i <= 5; i++) {
3  console.log(`Volta número ${i}`);
4}
5
6// while
7let tentativas = 0;
8while (tentativas < 3) {
9  tentativas++;
10}
11
12// for...of — percorre valores de um array
13const frutas = ["maçã", "banana", "uva"];
14for (const fruta of frutas) {
15  console.log(fruta);
16}
Atividade proposta
  1. Use um for para imprimir a tabuada de um número escolhido por você (de 1 a 10).
  2. Use um while para somar números de 1 até 100 e imprimir o total.
  3. Crie um array com 5 nomes e percorra-o com for...of, imprimindo uma saudação para cada um.
05

Funções

Funções agrupam código reutilizável. Você pode declará-las de forma tradicional ou como arrow functions (mais compactas).

funcoes.jsJavaScript
1// Declaração tradicional
2function somar(a, b) {
3  return a + b;
4}
5
6// Arrow function equivalente
7const somarArrow = (a, b) => a + b;
8
9// Parâmetro com valor padrão
10function saudacao(nome = "visitante") {
11  return `Olá, ${nome}!`;
12}
13
14console.log(somar(2, 3));      // 5
15console.log(saudacao());       // "Olá, visitante!"
Atividade proposta
  1. Crie uma função calcularMedia(notas) que recebe um array de notas e retorna a média.
  2. Crie uma arrow function ehPar(numero) que retorna true ou false.
  3. Desafio: escreva uma função converterTemperatura(valor, unidade) que converte entre Celsius e Fahrenheit dependendo da unidade recebida.
06

Arrays

Arrays armazenam listas ordenadas de valores. JavaScript oferece métodos poderosos para transformar essas listas sem escrever loops manuais.

arrays.jsJavaScript
1const numeros = [1, 2, 3, 4, 5];
2
3// map — transforma cada item
4const dobrados = numeros.map(n => n * 2);
5
6// filter — mantém só o que passa na condição
7const pares = numeros.filter(n => n % 2 === 0);
8
9// reduce — acumula os itens em um único valor
10const soma = numeros.reduce((total, n) => total + n, 0);
11
12console.log(dobrados); // [2, 4, 6, 8, 10]
13console.log(pares);    // [2, 4]
14console.log(soma);     // 15
Atividade proposta
  1. Dado um array de preços, use map para aplicar 10% de desconto em todos eles.
  2. Dado um array de idades, use filter para retornar apenas as maiores de idade.
  3. Use reduce para encontrar o maior valor de um array sem usar Math.max.
07

Objetos

Objetos guardam dados relacionados em pares de chave e valor, e podem incluir também funções (métodos).

objetos.jsJavaScript
1const produto = {
2  nome: "Teclado mecânico",
3  preco: 350,
4  estoque: 12,
5  disponivel() {
6    return this.estoque > 0;
7  }
8};
9
10// Acesso a propriedades
11console.log(produto.nome);        // "Teclado mecânico"
12console.log(produto["preco"]);   // 350
13console.log(produto.disponivel()); // true
14
15// Desestruturação
16const { nome, preco } = produto;
Atividade proposta
  1. Crie um objeto pessoa com nome, idade e um método apresentar() que retorna uma frase usando this.
  2. Crie um array de 3 objetos produto e use map para extrair só os nomes.
  3. Pratique a desestruturação extraindo duas propriedades de um objeto em uma única linha.

Manipulando o DOM

O DOM (Document Object Model) é a representação da página HTML em forma de objetos que o JavaScript pode ler e modificar.

dom.jsJavaScript
1// Selecionar elementos
2const titulo = document.querySelector("h1");
3const itens = document.querySelectorAll(".item");
4
5// Alterar conteúdo e estilo
6titulo.textContent = "Novo título";
7titulo.style.color = "tomato";
8
9// Criar e inserir elementos
10const novoItem = document.createElement("li");
11novoItem.textContent = "Item novo";

Atividade proposta
  1. Em uma página HTML simples, selecione um parágrafo e altere seu texto via console.
  2. Crie dinamicamente 5 itens de lista e insira-os em uma <ul> existente.
  3. Desafio: alterne a classe CSS de um elemento (tema claro/escuro) usando classList.toggle.

Eventos permitem que seu código reaja a ações do usuário, como cliques, digitação e envio de formulários.

2
3botao.addEventListener("click", () => {
4  console.log("Botão clicado!");
5});
6
7const campo = document.querySelector("#nome");
8campo.addEventListener("input", (evento) => {
9  console.log(`Digitando: ${evento.target.value}`);
10});
Atividade proposta
  1. Crie um botão que, ao ser clicado, incrementa um contador exibido na tela.
  2. Crie um campo de texto que exiba, em tempo real, quantos caracteres foram digitados.
  3. Desafio: crie um pequeno formulário que valide se o campo não está vazio antes de exibir uma mensagem de sucesso.

Assincronismo: Promises e async/await

Operações como buscar dados de um servidor levam tempo. Promises representam um valor que estará disponível no futuro, e async/await torna esse código mais fácil de ler.

assincronismo.jsJavaScript
1// Usando then/catch
2fetch("https://api.exemplo.com/usuarios")
3  .then(resposta => resposta.json())
4  .then(dados => console.log(dados))
5  .catch(erro => console.error(erro));
6
7// Mesma coisa com async/await
8async function buscarUsuarios() {
9  try {
10    const resposta = await fetch("https://api.exemplo.com/usuarios");
11    const dados = await resposta.json();
12    console.log(dados);
13  } catch (erro) {
14    console.error("Falha ao buscar:", erro);
15  }
16}
Atividade proposta
  1. Use a API pública https://jsonplaceholder.typicode.com/users com fetch e exiba os nomes no console.
  2. Reescreva a mesma busca usando async/await com tratamento de erro via try/catch.
  3. Desafio: crie uma função que simule uma espera de 2 segundos com setTimeout envolto em uma Promise, e use await para esperá-la.

Projeto final proposto

Para consolidar tudo o que foi visto, construa uma lista de tarefas (to-do list) usando apenas HTML, CSS e JavaScript puro (sem frameworks).

Requisitos

  • Um campo de texto e um botão para adicionar novas tarefas.
  • Cada tarefa deve poder ser marcada como concluída (clique para riscar o texto).
  • Cada tarefa deve ter um botão de remover.
  • Exiba um contador de "tarefas pendentes" que atualiza automaticamente.
  • Use addEventListener, manipulação do DOM e ao menos um método de array (filter ou map).
Extensões (opcional)
  1. Salve as tarefas no localStorage para que não se percam ao recarregar a página.
  2. Adicione filtros: "todas", "pendentes", "concluídas".
  3. Adicione uma animação simples ao adicionar ou remover um item.
