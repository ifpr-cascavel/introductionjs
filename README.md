## Como usar

Não há build, dependências ou instalação. É um único arquivo HTML autocontido.

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
cd seu-repositorio
```

Depois é só abrir o arquivo no navegador:

```bash
open javascript-tutorial.html      # macOS
xdg-open javascript-tutorial.html  # Linux
start javascript-tutorial.html     # Windows
```

Ou publique com **GitHub Pages** em poucos cliques:

1. Vá em `Settings` → `Pages`
2. Em *Source*, selecione a branch `main` e a pasta `/root`
3. Acesse o link gerado pelo GitHub

## Contribuindo

4. Abra um Pull Request
